# Homeless Society Sim — 계약하기 전에 30일 먼저 살아 보기

[English README](README.md)

**Meta Global AI Developer Hackathon · Indie Developer 트랙 · "Build for Your World"**

**Gen-Z를 위한 부동산 지식의 민주화.** 한국의 사회초년생, 결혼을 앞둔 커플, 어린 자녀가 있는 가족에게 집은 인생에서 가장 크고 위험한 결정이에요. 그런데 대부분은 매물 정보와 가격, 주변의 조언만으로 결정해요. 매물 정보는 그 집에서 한 달을 살면 어떤지 알려 주지 않아요. 역까지 몇 분 걸리는지, 아침 8시 열차가 얼마나 붐비는지, 퇴근하면 얼마나 지치는지, 학교가 얼마나 가까운지, 주거비를 내고 나면 얼마가 남는지 같은 것들이요. 대출을 받아 사는 게 전·월세보다 정말 나은지, 이 전세에 위험 신호는 없는지, 내 연봉으로 받을 수 있는 공공임대와 정부 지원은 무엇인지도 알려 주지 않아요.

전세사기는 특히 젊은 세입자에게 큰 피해를 줬어요. 피해자의 약 75%가 20·30대예요(2025년 3월 보도, 국토교통부 자료 인용). 저희는 **계약하기 전에 그 집에서 미리 살아 보고, 돈을 계산해 보고, 위험 신호를 확인하고, 받을 수 있는 지원을 볼 수 있어야 한다**고 생각해요.

그래서 이 질문들에 실제 공공 데이터로 답하는 시뮬레이터를 만들었어요. **시뮬레이션 속 한 사람 또는 두 사람(또는 가족)이 A집과 B집에서 각각 30일을 살아요.** 실제 동네를 옮긴 3D 모형 위에서 두 결과를 나란히 보여 줘요. 그다음 시간, 돈, 생활 편의, 교육 접근성, 공식 치안 통계를 **고객이 직접 정한 우선순위**로만 비교하고, 모든 숫자가 어디서 나왔는지 설명해요. 앱은 보여 주고 설명할 뿐이고, 결정은 고객이 해요.

> 상태: 개발 중이에요(해커톤 기간 2026-10-27 → 11-04). 첫 커밋은 2026-10-28이고, 해커톤 이전에 만든 코드는 없어요. [알려진 문제](#알려진-문제)도 함께 봐 주세요.

## 하는 일

![사람 따라가기: 지금 카드에 무엇을, 왜 하는지, 적용된 기준, 피로도가 보여요 (실제 GPU 캡처, 2026-10-29)](briefs/img/08c-follow.png)


- **실제 동네를 3D로 만들어요.** OpenStreetMap과 국가 건축물 정보로 건물 윤곽, 높이, 층수, 아파트 단지, 도로, 역, 공원, 상점을 세워요. 지금은 판교, 성수, 송파구, 잠실 네 지역이 있어요.
- **30일 동안의 생활을 시뮬레이션해요.** 가구(성인 2명)와 이웃 60명이 실제 도보 경로를 따라 출근하고, 장을 보고, 공원을 걷고, 병원에 가요. 이웃은 모두 시뮬레이션 주민이라고 표시해요. 엔진은 결정적이라서, 같은 시드를 넣으면 바이트 단위까지 같은 결과가 나와요.
- **선택은 Muse가, 계산은 엔진이 해요.** 어디서 장을 볼지, 주말에 무엇을 할지, 퇴근길에 들를지 같은 판단 지점이 오면 엔진이 선택지를 내놓아요. Muse Spark 1.3이 그중 하나를 고르고 이유를 남겨요. 데모 실행에서 Muse는 198번 판단했고, 그중 50번은 규칙 기본값과 다르게 골랐어요. 화면의 숫자는 모두 데이터나 엔진에서 나와요. 모델 답변에 도구 결과에 없는 숫자가 들어가면 검사 장치가 그 답을 거절해요.
- **재생 중에 지금 무엇을, 왜 하는지 보여 줘요.** "지금" 카드에 현재 활동과 그 원인을 띄워요. 원인은 생활 규칙, 이유가 달린 Muse 판단, 고객 입력 중 하나예요. 적용된 기준과 다음 일정도 함께 보여 줘요. 따라가는 사람과 경로, 목적지는 화면에서 강조해요.
- **시뮬레이션 기준을 모두 공개해요.** 엔진이 쓰는 규칙과 가정값은 [`scenarios/criteria/kr-default.json`](scenarios/criteria/kr-default.json) 한 파일에 있어요. 읽기 쉽게 정리한 문서는 [`docs/criteria.md`](docs/criteria.md)예요. 기준마다 출처(엔진 기본값, 고객 입력, 데이터, 가정값)가 붙어 있어요. 바꿀 수 있는 기준은 고객이 고친 뒤 다시 돌려 볼 수 있어요.
- **연봉에 맞춰 생활비를 계산해요.** 연봉과 보유 현금을 넣으면 실수령액을 추정해요. 실제 금액을 직접 넣어도 돼요. 그다음 매매, 전세, 월세, 공공임대 각각 매달 집에 드는 돈을 계산해요. 가격은 같은 단지, 비슷한 면적의 **최근 12개월 실거래**를 쓰고, 취소된 거래는 빼요. 30일 동안의 지출도 시뮬레이션 속 실제 활동에 맞춰 나가요. 지하철을 탈 때마다 교통비가, 장을 볼 때마다 장보기 비용이 나가요.
- **비슷한 공공임대를 추천해요.** 공공주택 데이터 API(LH·마이홈)에서 주거비 부담률, 면적, 출퇴근 조건에 맞는 곳을 골라요. 후보마다 공고 원문 링크를 붙이고, 누르면 C집으로 추가해서 똑같이 시뮬레이션해요.
- **상담 에이전트가 있어요.** 도구 20개 이상을 가진 Muse 에이전트예요. 대화로 조건을 정하고, 시뮬레이션을 돌리고, 결과를 비교해요. 판단과 기준을 설명하면서 3D 화면을 그 장면으로 옮겨 보여 줘요.
- **상황별 시작과 내 우선순위(9a단계).** 1인 사회초년생, 예비·신혼부부, 초등학생 자녀가 있는 맞벌이 중에서 골라 시작해요. 교육 · 우리의 생활 · 치안 · 돈 · 편의 비중은 고객이 직접 정하고, "내 기준으로 보기"에서 나란히 비교해요. 치안은 경찰청 공식 발생 건수, 교육은 OSM 기반 학교 접근성이에요. 점수나 순위로 묶지 않아요.
- **5·10·20년 동안 "살 만한가?"(9b단계).** 매매·전세·월세·공공임대를 나란히 놓고 총지출, 이자, 묶이는 돈, 기회비용(고객이 정한 수익률), 연도별 대출 상환표, 금리 +1·+2%p 시험, DSR을 보여 줘요. 집값 변화는 고객이 고른 시나리오(기본 연 −2·0·+2%)로만 보여 주고 "가정 시나리오, 전망 아님"이라고 붙여요. 시나리오마다 손익이 바뀌는 해를 보여 줄 뿐, 사라/사지 말라고 하지 않아요.
- **전세 안전 점검(9b단계).** 같은 단지·면적의 실거래로 계산한 전세가율(예: 레이크팰리스 59.97㎡ 37%), 건축물대장 신호, 공식 6단계 체크리스트(등기부등본, 전입·확정일자, 보증보험, 세금 체납 확인 등, 모두 공식 사이트 링크), 그리고 **보증금을 돌려받지 못하는 모의 시뮬레이션**(보증보험·경매·미회수 경로, 가정값 공개)을 보여 줘요. 신호와 다음 할 일을 알려 줄 뿐 "안전/위험"을 판정하지 않고, 법률 자문도 아니에요.
- **지원 제도 한눈에(9b단계, 2026-10-29 공식 페이지 확인).** 버팀목 전세, 청년전용 버팀목, 신혼부부전용 전세, 디딤돌, 신생아 특례 디딤돌의 소득·자산·금리·한도·보증금/주택가격 조건을 주택도시기금 공식 상품 페이지에서 옮기고, 출처 링크와 날짜를 붙였어요. 고객이 넣은 숫자와 조건을 하나씩 대조하고 예외는 쉬운 말로 풀어요. "대상입니다"라고 판정하지 않아요.
- **집이 정해 주는 진짜 출퇴근(9c단계).** 직장을 장소로 정하면 집마다 출퇴근 방법을 따로 계산해요. A(잠실)에서는 역까지 걷고 2호선 → 신분당선을 타고 다시 걸어요. B(판교)에서는 걸어서 가요. 지하철 탑승은 별도 이동으로 다루고, 구간마다 혼잡도와 출처를 지금 카드에 보여 줘요.
- **어디서나 쉬운 말(10단계).** 숫자가 무슨 뜻인지 일상어로 먼저 말해요. "월 주거비 (전세)"는 "전세로 살면 매달 집에 드는 돈", "주거비 부담률"은 "월급에서 집에 나가는 비율", "출근 도착 피로도"는 "회사 도착할 때 피곤한 정도"가 됐어요. 숫자마다 "어떻게 계산했나요?"를 펼칠 수 있어요. 전문 용어는 풀이 말풍선과 함께만 쓰고, 테스트가 화면 문구를 검사해요([`docs/copy-guide.md`](docs/copy-guide.md)).
- **떠 있는 AI 에이전트(10단계).** "물어보기" 버튼을 누르면 Astryx 채팅 창(Popover, ChatLayout, ChatToolCalls, ChatSystemMessage, Citation, ChatComposer)이 떠요. 지금 화면에 맞는 추천 질문("이 출근길 왜 피곤해요?")이 나오고, "이거"가 무엇인지 알아들어요. 도구를 쓸 때마다 단계를 보여 주고 출처를 모두 달아요. 눈여겨볼 순간에는 1분에 한 번까지만 살짝 알려 줘요.
- **내가 찾은 실제 매물 확인(10단계).** 부동산 앱에서 본 매물 글을 붙여 넣으면, 글에 있는 값만 뽑아 단지를 찾고 최근 1년 실거래 가운데 어디쯤인지 보여 줘요(예: 전세 9.8억 → 47건 중 한가운데, 범위 7.61억~11.8억). 전세가율과 체크리스트도 함께 보여 주고, 누르면 C집으로 30일 살아 봐요. 민간 매물 사이트는 긁어 오지 않아요. LH·SH·청년주택 공고는 공식 API에서 받아 원문 링크를 붙여요.
- **결과 공유 카드와 3분 둘러보기(10단계).** "결과 공유"를 누르면 A·B를 쉬운 말로 비교한 이미지(PNG)와 인쇄용 페이지를 만들어요. 출처 배지와 가정값 표시가 붙고, 어디에도 올리지 않아요. `?tour=demo`는 처음 쓰는 사람과 영상 녹화를 위한 11단계 안내예요.
- **지역을 가로질러 그 사람을 따라가요(8단계).** 따라가는 사람이 지하철을 타면 카메라가 위로 올라가요. 노선 주변 간략 지도(건물 10,971동, 필요할 때 불러오는 65칸) 위로 OSM의 실제 노선 모양(2·8·9호선, 수인분당선, 신분당선)을 따라 열차가 움직여요. 고객이 넣은 탑승 시간은 노선 길이에 비례해 나눠요. 예를 들어 잠실→판교는 2호선 8.6분 + 환승 4분 + 신분당선 17.4분이에요.
- **혼잡도 기반 피로도 지수(8단계).** 서울교통공사가 역, 방향, 30분 단위로 실측한 혼잡도를 써요(예: 2호선 잠실 08:00 내선 약 93%). 신분당선처럼 자료가 없는 노선은 "자료 없음"으로 표시하고 공개된 가정값을 써요. 가중치는 모두 공개돼 있고 바꿀 수 있는 기준이에요. 의학적 판단이 아니라 가정 모델이에요.

### 일부러 하지 않는 것

다음 일은 하지 않아요.
- 가격 전망. 가격 변화는 고객이 고른 가정 시나리오로만 보여 줘요.
- 사라/사지 말라, 계약하라/하지 말라는 조언
- 대출·지원 제도의 대상 여부 판정
- 특정 집이나 임대인에 대한 "안전/위험" 판정
- 치안·학교 종합 점수, 주민 구성 분석, 기본으로 정해 둔 "가장 좋은 집" 순위
- 직선거리 통근 주장

치안과 교육 수치는 출처, 기간, 지역 단위를 붙인 공식 통계만 써요. 가정한 값은 가정값이라고 표시해요. 이 앱의 어떤 내용도 법률·금융 자문이 아니에요.

가정한 입력은 연봉 6,000만 원과 5,000만 원, 현금 2억 원, 대출 금리, 잠실→판교 지하철 30분이에요. 화면에서는 모두 가정값으로 표시돼요. 표는 차이를 보여 줄 뿐이고, 무엇이 더 중요한지는 고객이 정해요.

## 만든 방법

이 저장소의 제품 코드, 테스트, 파이프라인 스크립트는 한 줄도 빠짐없이 **Muse**(`muse-spark-1.3`, Muse Code 에이전트 모드)가 작성했어요. 사람과 조율 담당 어시스턴트는 단계별 지시문을 쓰고, 데이터를 받고, 테스트를 돌리고, 실제 GPU로 화면을 캡처했어요. 지시문과 결과 기록은 모두 [`briefs/`](briefs/)에 있고, 작업 규칙은 [`AGENTS.md`](AGENTS.md)에 있어요.

| 층 | 위치 | 설명 |
|---|---|---|
| 데이터 파이프라인 (Python) | `pipeline/` | OSM 추출, 건축물대장 결합, 도보 그래프, 단지, 검증. 8단계에서 지하철망, 노선 주변 지도, 혼잡도를 추가해요 |
| 생활 엔진 (JS) | `web/src/engine/` | 생활 규칙, 판단, 원인이 붙은 이동, 돈 흐름, 기준 로더. 결정적이에요 |
| Muse 판단 층 | `web/src/judge/` | 판단 프롬프트, 숫자 검사, 똑같이 재생할 수 있도록 판단 기록 저장 |
| 상담 에이전트 | `web/src/consult/` | Meta API에 OpenAI 방식 도구 호출. 서버에서만 실행하고 키는 브라우저로 가지 않아요 |
| 돈과 가격 | `web/src/money/` | 급여 표, 매매·전세·월세 계산식, 실거래 CSV 로더, 공공임대 연결 |
| 3D 장면 | `web/src/render/`, `web/src/main.js` | three.js 0.170. 데이터로 만든 외벽 재질, 서울 위치의 하늘과 태양, 집에 있는 주민 수만큼 켜지는 창문 불빛 |
| UI | `web/src/ui/` | React 19 + **Astryx**(Meta 디자인 시스템) |

사용한 Meta 모델은 **Muse Spark 1.3**이에요. 가구 판단, 상담 에이전트, 그리고 이 저장소를 작성한 코딩 에이전트에 썼어요. Muse Spark Open은 추론 크레딧이 들어오면 돌릴 예정이에요.

테스트는 `node --test` 581개(화면 없이 시뮬레이션 로딩 확인, React 화면 전체 렌더 확인, 쉬운 말 검사 포함), `pytest` 168개예요.

## 실행 방법

준비물: Node 20 이상, Python 3.12, 원본 데이터용 디스크 약 6GB.

```bash
# 1. Python 파이프라인
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
# data/raw/에 south-korea-latest.osm.pbf(Geofabrik)를,
# data/raw/buildings/<지역>/에 GIS건물통합정보 shapefile을 둬요 (ATTRIBUTION.md 참고)
.venv/bin/python -m pipeline build --all
.venv/bin/python -m pipeline.validate --all

# 2. 시뮬레이션 실행
cd web && npm install && cd ..
node web/scripts/simulate.mjs --scenario scenarios/demo-two-homes.json --home both --out data/build/sim/
node web/scripts/money.mjs   --scenario scenarios/demo-two-homes.json --out data/build/sim/

# 3. 앱 (상담 에이전트와 실시간 판단은 서버 환경에 Meta API 키가 있어야 해요)
cd web && MODEL_API_KEY=... npm run dev
```

자주 쓰는 주소 (`/?mode=sim&scenario=demo-two-homes` 뒤에 붙여요):
- `&tour=demo` (3분 둘러보기)
- `&home=A&day=1&t=08:50&follow=1` (출근길 따라가기)
- `&tab=money` (생활비), `&tab=listings` (매물 확인, `&fill=example`은 예시 표시), `&tab=money&share=1` (결과 공유 카드), `&tab=criteria` (기준)
- `/?area=seongsu&shot=3&time=18:30` (풍경 투어)

원본 데이터와 가공 데이터는 커밋하지 않아요. 위 스크립트로 다시 만들 수 있어요. 실거래 CSV, 공공임대 스냅샷, 지하철 혼잡도 파일은 운영자가 직접 받아 로컬에만 둬요. 각 자료의 이용 조건이 그렇게 정하고 있어요.

## 알려진 문제

- 10b단계 뒤 실제 GPU에서 확인한 것(2026-10-29): 떠 있는 에이전트 창이 비교 카드와 매물 탭을 가릴 때가 있어요. 일부 탭 이름과 머리 버튼 글자가 잘려요. 공유 카드에 A·B 숫자가 적게 나와요. 낮 화면과 지역 이동 화면은 아직 희뿌옇고, 밤 불빛도 아직 밝아요. 다음 단계에서 다듬어요.
- `?q=high`는 Apple GPU(ANGLE Metal)에서 검은 화면이 나와서, 앱이 감지하면 중간 품질로 자동으로 낮춰요.
- `scenarios/assumptions/kr-payroll.json`의 4대보험·소득세 요율과 집을 살 때 드는 비용(취득세, 중개수수료, 재산세 등)은 "확인 필요"로 표시돼 있어요. 공식 페이지에서 채우기 전까지는 "아직 계산에 넣지 않은 것"으로 보여 줘요.
- 지하철 탑승 시간은 시간표가 아니라 고객이 넣은 가정값이에요. 신분당선은 공개된 혼잡도 자료가 없어서 70% 가정값을 써요.
- 성남시 범죄 통계는 시 단위, 서울은 구 단위예요. 수치마다 지역 단위를 함께 보여 줘요.
- 공공주택 API에는 마감일 항목이 없어서 "최근 공고"로 보여 주고 원문 링크를 붙여요.
