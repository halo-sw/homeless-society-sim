## Part B — salary → monthly living-cost simulation (engine + UI + agent)
1. **Inputs** (scenario `money` block, documented in `docs/scenario-schema.md`; entered through the consult agent or a small Astryx form): per member `annual_salary_won` and/or `monthly_net_won`; household `cash_won` (own funds); `tenure` per home: 매매 / 전세 / 월세 / 공공임대; assumptions with source labels: `loan_rate_pct`, `loan_years`, `maintenance_won_month` (관리비), `transit_fare_won`, `basket_won` (per grocery trip), `other_fixed_won_month`. Every assumption is labelled 가정값 on screen and editable.
2. **Net pay.** If only gross salary is given, estimate net pay with a documented, replaceable rule table `scenarios/assumptions/kr-payroll.json` (social insurance rates + simplified income tax table, with `as_of` and `source` fields; mark any rate you are not certain of `"needs_confirmation": true`). The UI shows "추정 실수령액" with the breakdown and lets the customer type the real number instead. Never store income server-side.
3. **Housing cost per tenure** (monthly + one-off), from real data (Part C): 월세 = deposit from cash + monthly rent; 전세 = (전세금 − cash) × rate / 12 when positive; 매매 = amortised payment on (price − cash) over `loan_years` at `loan_rate_pct` + note that taxes/fees are not included; 공공임대 = API deposit + monthly rent. Show "대출 가능 여부(LTV·DSR)와 입주 자격은 판단하지 않습니다".
4. **30-day money timeline from the simulation.** The engine emits spending events tied to real simulated activity: transit fare per commute trip (from trips that leave by station), grocery basket per errand trip, fixed costs on their due day, salary on payday. Output per home: daily balance series, monthly totals by category, 주거비 부담률 (housing cost ÷ monthly net), and 남는 돈. Deterministic like the rest.
5. **UI:** a "생활비" tab next to A·B 비교: stacked monthly bars by category for A / B (and C if a public rental is added), the balance line over 30 days (simple SVG or canvas, Astryx tokens), and the tenure switch (매매/전세/월세/공공임대) per home.

## Part C — real prices and public rental (data adapters; tests on local snapshots)
1. **Real transactions** from `data/raw/rtms/*.csv` (18 files: apt / rowhouse / officetel × trade / rent × 송파 / 성동 / 분당, 2025-10-28…2026-10-27; format in `briefs/notes/rtms-download.md`). Loader with two backends behind one interface: CSV now, data.go.kr API later (fields per `data/raw/docs/TransactionPrice.md`; not callable today). Exclude cancelled deals (`해제사유발생일` non-empty). Match to our complexes by 시군구 + 본번/부번 → PNU (bjdong code from our register data), check with 단지명. Reference price per complex and area bucket (±5 ㎡): median, p25–p75, count, period; rent split into 전세 vs 월세 (보증금, 월세금). Show the source disclaimer ("참고용, 법적 효력 없음, 계약일 기준").
2. **Public rental** (`data/raw/public_housing/snapshot_3districts.json`, fetched by the orchestrator from the public-housing API: LH complexes with `pnu` and `unit_types` [unit_type, building_type, exclusive_area_m2, deposit_won, monthly_rent_won], youth complexes with lat/lon, notices with `source_url`). Runtime adapter calls the API server-side only (`HOUSING_API_KEY`, base `https://public-housing-map.vercel.app/api/v1`, GET `/complexes`, `/complexes/{source}/{id}`, `/notices`; Bearer auth); tests use the snapshot. **Do not commit the snapshot or any API output.** Attribution: "LH·마이홈 (공공주택 데이터 API, 스냅샷 시각 표시)".
3. **Recommend similar public rental:** candidates whose monthly housing cost keeps 주거비 부담률 under the customer's threshold (default 30 %, labelled as a common rule of thumb, editable), similar exclusive area (±10 ㎡ of the compared home), and shortest commute to the customer's work station (graph minutes when the complex is inside a built area via PNU — 송파구 154, 판교 4 [백현마을 3·4단지, 봇들마을 5·6단지], 성수 3 — else listed with address and "시뮬레이션은 지역 생성 후"). Each candidate links its notices (`source_url`) with "입주 자격은 공고 원문에서 확인". One click "C로 추가" runs the 30-day simulation for it as home C.
4. **Agent tools:** `set_money(patch)`, `estimate_net_pay(annual)`, `price_reference(area, complex, area_m2, tenure)`, `living_cost(run, tenure)`, `recommend_public_rental(criteria)`, `add_home_c(candidate)`. Numbers only from tools; guards extended (no forecasts, no loan/eligibility judgement, no "buy/don't buy").
