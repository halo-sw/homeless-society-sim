## 한 줄
집 고민을 Muse에게 물어보세요. Muse가 직접 확인하고, 대신 30일 살아 보고, 대화로 알려 줘요.

## 원칙
1. **대화가 전부예요.** 탭·모드("대화 / 살아 보기 / 동네 둘러보기")와 소개 페이지는 없어요. 들어오면 바로 Muse와의 대화예요.
2. **요청한 것만 열려요.** 처음엔 대화만 있어요. 지도·비교·동네 둘러보기·살아 본 결과는 사용자가 요청했을 때 오른쪽 작업판에 열려요. 작업판의 탭도 지나온 단계만 하나씩 늘어나요. 작업판은 언제든 닫을 수 있어요.
3. **Muse는 제안하고, 시작은 사용자가 해요.** 다음에 할 수 있는 일은 답 끝의 버튼 2~3개로 제안해요. 버튼을 누르는 것과 같은 말을 입력하는 것은 똑같이 처리돼요. 비싼 일(30일 살아 보기)은 사용자가 맡길 때만 돌아요.
4. **기능은 모두 Muse의 도구예요.** 지금 있는 기능은 사용자가 말로 요청하면 Muse가 골라 쓰는 도구가 돼요. Muse가 도구를 쓸 때마다 대화에 ▸ 줄이 남아요.
5. **Muse는 판단하고, 엔진은 세고, 코드는 검사해요.** 숫자(시간·거리·돈)는 모두 도구에서 나와요. Muse는 사람처럼 판단하고 설명해요. 결과 문장은 기록과 대조해요.
6. **묻기 전에 먼저 보여 줘요.** 모르는 값은 기본값으로 채우고 "가정함"으로 표시해요. 질문은 한 번에 하나, 답 버튼과 "건너뛰기"를 함께 줘요. 설문지는 없어요.
7. **멈추지 않아요.** 1초 안에 반응(지금 하는 일 표시)하고, 어떤 말에도 답해요. 다루지 않는 지역·막연한 말·엉뚱한 질문에도 짧게 답하고 다음 버튼을 줘요. Muse 연결이 안 되면 규칙으로 답하고 "Muse 연결 안 됨 · 규칙으로 답했어요"라고 표시해요.
8. **대화는 남아요.** 집 고민 하나가 대화 하나예요. 닫았다 열어도 이어져요. 지난 대화는 ☰ 서랍에 있어요.

## 화면
- 왼쪽(또는 가운데): 대화. 위에 Muse 얼굴·이름·연결 상태(실제 모델 이름), 아래 입력 칸(+ 매물 글 붙이기).
- 오른쪽: 작업판 — 요청하면 열려요. 지도 · 비교 · 동네 · 출근길 · 살아 본 결과. 위에 "● Muse 작업 중 12/30"(누르면 Muse가 한 일 기록).
- 첫 화면: 가운데 "어떤 집을 고민 중이세요?" + 입력 칸 + 시작 버튼 3개(출근지로 집 찾기 · 본 매물 붙여 넣기 · 예시로 써 보기) + 다루는 지역 한 줄.
- 휴대폰: 대화가 전체 화면, 작업판은 위쪽 전환 또는 카드를 누르면 전체 화면.

## 요청 → 도구 → 작업판 (지금 있는 기능 전부)

| "이 동네 어때?" / "집 주변 걸어 보고 싶어" | 동네 둘러보기 (실제 걷는 길로 역·마트·공원) | 3D 동네 걷기 + 곳마다 걸어서 몇 분 |

| "두 집 비교해 줘" | 비교 | 돈·출근·확인할 것 나란히 |

## 대화 예시 (시연도 이 흐름 그대로, 실제 앱을 촬영)
> 나: 판교 출근하는 신입이에요. 전세 2억 이하로 혼자 살 집 찾아 줘.
> Muse: ▸ 실거래 확인 ▸ 출근 계산 — 41곳이에요. *(지도 열림)* `출근 짧은 곳만` `월세도 보기`
> 나: 분당오벨리스크 동네는 어때?
> Muse: ▸ 동네 둘러보기 — 역까지 7분, 마트 4분, 공원 9분. 같이 걸어 볼게요. *(3D 동네)*
> 나: 여기랑 천사의도시 찜.
> Muse: 두 곳 찜했어요. `비교해 줘` `출근길 보여 줘` `살아 봐 줘`
> 나: 살아 봐 줘.
> Muse: 30일 살아 볼게요. 끝나면 알려 드릴게요. *(작업 중 12/30)* … 결과 한 문단 + `결과 보기`
> 나: 밤에 퇴근하면 어때?
> Muse: ▸ 30일 기록 검색 — 밤 10시 이후 귀가 3번 … `그 장면 보기`
